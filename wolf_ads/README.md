# Wolf ads (draft pipeline)

Free tools only: Python (Pillow, numpy) and ffmpeg. Screens are simulated.

- `neo.py NAME` renders a video into `out_neo/`. Names: `long` (add `--parallel`), `demo`, `ad1`-`ad4`, `dan`, `mum`, `family`.
- `neo.py NAME --preview 1.0,2.5` writes still frames only.
- `shots/` are FLUX.1-Krea stills (AI people, adults, child from behind only). Add `shots/holiday.png` to enable the holiday photo scene.
- `assets/wolf_mark_v4_512.png` is the Wolf mark from Drive.
- Claims shown: calendar-connected, finds options, answers questions, books nothing. Box is a labelled "coming soon" concept.
- Nothing here is approved or posted. Vetting (trend, psychology, legal, Chief of Staff) is still to do.
