## 6. Top 5 changes (with ethics tests)
1. Add "Watch the full video: [link in bio]" to the end card. Disclosure pass, reversal pass, truth pass if the link works.
2. Replace the age line with one policy [Jay to decide], e.g. "Adults 18+. Under 16s need a parent's OK" only if 16-17 is handled. Truth: cannot tell until policy is set.
3. "from £69." becomes "£69 per person." if £69 is the only individual price. Truth: cannot tell until confirmed.
4. Add "Standard package: AI, calendar and email checks" to the end card so add-ons are not read as included. Truth pass.
5. Add one real pilot quote when collected. Truth: cannot tell until collected.

Hypothesis cards (top 3):
- H1: Because a prompt at the moment of interest addresses the missing call to action (L27, no effect grade), adding "Watch the full video: [link]" to the end card should raise link taps for UK parents. Legitimate only if: the link works. Variant: one change against the current end card. Guardrails: unsubscribes, complaints. Decision rule: a lift together with a guardrail breach counts as a failed test. To size and read this test, use a conversion-rate-optimisation (A/B testing) skill, a sample-size tool or your experimentation platform. Feasibility: at scale, nudge-type changes averaged +1.4 percentage points, an 8.0% relative increase (L21); effects that small usually take more than ten thousand visitors per version to detect. On lower traffic, ship only honest, low-risk changes and claim no lift.
- H2: Because a clear single price addresses unclear price framing (L10, B), changing "from £69" to "£69 per person, one-off" should raise understanding of the price. Legitimate only if: £69 is the individual price and one-off is true. Guardrails: refunds, complaints. Same feasibility note.
- H3: Because real proof addresses missing proof for this reader (L05, B, only when true and about people like them), adding one pilot quote should raise trust for UK parents. Legitimate only if: the quote is real, with permission. Guardrails: complaints, unsubscribes. Same feasibility note.
